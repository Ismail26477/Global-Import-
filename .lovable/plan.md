

# Global Imports - Premium B2B Website Plan

## Overview
A modern, corporate single-page website for Global Imports that builds trust with international B2B clients. The design will feature a dark blue, white, and gold color scheme with smooth animations and professional typography.

---

## 🎨 Design & Branding
- **Color Theme**: Dark navy blue (#1a365d), white, and gold accents (#d4af37)
- **Typography**: Poppins/Montserrat (modern, corporate feel)
- **Style**: Glassmorphism header, subtle world map patterns, parallax backgrounds
- **Overall Feel**: Premium, trustworthy, international

## ✨ Interactive Features

### 1. Contact Form Popup (5 seconds)
- Appears automatically 5 seconds after page loads
- Overlay modal with close button
- Fields: Name, Email, Phone, Product Interest, Message
- "Don't show again" checkbox (saves to localStorage)
- Smooth fade-in animation

### 2. WhatsApp Floating Button
- Fixed position, bottom-right corner
- Green WhatsApp icon with pulse animation
- Opens chat with +91 9270109911
- Hover tooltip: "Chat with us!"

### 3. Simple FAQ Chatbot
- Floating chat widget (bottom-right, above WhatsApp)
- Click to expand chat window
- Pre-programmed responses for:
  - "What do you import?"
  - "Shipping time?"
  - "Minimum order quantity?"
  - "How to get a quote?"
  - "Your certifications?"
  - "Payment methods?"
- Quick-reply buttons for common questions
- "Speak to a human" option connects to WhatsApp

### 4. Live Shipment Tracker UI
- Input field for tracking ID
- Animated status timeline (visual design only)
